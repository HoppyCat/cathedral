# SoulMode Agent Templates

These templates remain available in case a human or agent finds them useful.

With rare exceptions, Cathedral itself no longer uses most of the documents in
this section as part of its current working practice. They are preserved online
for historical provenance and as optional reference material, not as a statement
of Cathedral's present architecture, required procedures, or active defaults.

The collection currently includes:

- `guided-setup/`
- `on-demand/`
- `on-load/`

Anyone choosing to reuse or adapt these materials should review them against
their current tools, needs, privacy requirements, and safety boundaries. Their
continued presence records an earlier stage of the project and leaves useful
parts available without implying that the full template system is still in use.
